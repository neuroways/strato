- Vite

## Nach Integration
```bash
cd frontend
npm install
npm run test:foundation
npm run typecheck
npm run build
npm run dev
```

`node_modules/` und `dist/` gehören nicht ins Git. `package-lock.json` soll nach dem ersten realen `npm install` ins Git.
