## Archivierungsformat

**Diese Datei dient als:**

1. **Fotografisch erfasster Zwischenbestand** — Grundlage für digitale Erfassung
2. **Prüfliste für Editions-Komplettierung** — offene Punkte klar gekennzeichnet
3. **Referenz für zukünftige Katalogisierung** — strukturierte Tabellen zum Import/Übertrag in Datenbank-Sammlung
4. **Nachvollziehbare Quelle** — Status-Legende ermöglicht Unterscheidung zwischen sicher erkannt, wahrscheinlich und offen

**Nicht enthalten:**

- Verdeckte oder verborgen gelagerte Spiele, Karten, Puzzle
- Editionen, Produktnummern, Erwerbsdaten, Zustand-Bewertung
- Regelwerk-Kopien, Anleitungen als Dateien
- Spielwert-, Komplexitäts- oder Alterseinstufungen
