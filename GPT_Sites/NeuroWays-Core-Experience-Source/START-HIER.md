# NeuroWays Core Experience – Quellcode-Export

Dieser Export enthält den weiterbearbeitbaren Quellcode der veröffentlichten NeuroWays Core Experience.

## Lokal starten

Voraussetzung: Node.js 22.13 oder neuer.

```bash
npm install
npm run dev
```

Anschließend die im Terminal angezeigte lokale Adresse im Browser öffnen.

## Wichtige Dateien

- `app/page.tsx` – Inhalt, Zustände und Interaktionen
- `app/globals.css` – Gestaltung, responsive Regeln und Wirkmodi
- `app/layout.tsx` – Seitentitel und Grundlayout
- `public/` – öffentliche Bild- und Icon-Dateien

## Hinweise

- Nicht enthalten sind installierte Abhängigkeiten, temporäre Build-Dateien und Zugangsdaten.
- Die veröffentlichte Seite bleibt durch diesen Download unverändert online.
- Der Export ist ein React-/TypeScript-Projekt und keine einzelne statische HTML-Datei.
