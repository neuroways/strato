# Server Root – Zielstruktur

Spiegelt die geplante Struktur direkt unterhalb des NeuroWays-Webspace-Roots. Noch nicht direkt über bestehende Produktivpfade kopieren.

## Regeln

- Private und öffentliche Bereiche sind getrennt.
- DEV und PRO sind strukturell symmetrisch, aber logisch isoliert.
- Verfügbare Package-Versionen und konkrete Installationen sind getrennt.

## Status

Teil des `NW-ARCH-008 STRATO Server Blueprint v0.1.0 Draft-Pilot`. Diese Struktur ist ein Architektur-Scaffold, keine produktive Runtime-Freigabe.
