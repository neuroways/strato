# Secrets

Reservierter privater Bereich für serverseitige Secrets bzw. Secret-Resolver. Darf niemals öffentlich erreichbar oder Bestandteil von Module Packages sein.

## Regeln

- Default: kein Secret im Repository.
- Spätere Implementierung bevorzugt sichere zentrale Verwaltung statt Moduldateien.
