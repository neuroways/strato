# ADR-NBK-003 – DEV-Fixtures statt erfundener Produktinhalte

- Status: Accepted for DEV-Pilot
- Datum: 2026-08-20

## Entscheidung
Solange die vollständige freigegebene Kartenquelle und Originalassets nicht im Migrationskontext vorliegen,
verwendet die lauffähige Vorschau ausschließlich klar markierte technische Testkarten.

## Begründung
Eine technische Migration darf keine fachlichen Karteninhalte erfinden und anschließend versehentlich als
NeuroBalance-Produktbestand etablieren.
