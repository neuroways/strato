# ADR-NBK-002 – Persönliche Erstwahrnehmung bleibt eigenständig

- Status: Accepted for DEV-Pilot
- Datum: 2026-08-20
- Betroffener Scope: Kartenmoment / Reflexion

## Entscheidung
Die erste persönliche Wahrnehmung einer aufgedeckten Karte wird als eigener fachlicher Wert behandelt.

Ein später eingeblendeter Kartentext, eine Reflexion oder eine KI-Begleitung darf:
- die Erstwahrnehmung nicht überschreiben,
- sie nicht als richtig oder falsch markieren,
- sie nicht stillschweigend neu interpretieren.

## Auswirkung
Produktive Persistenz benötigt getrennte Felder/Objekte für Erstwahrnehmung und spätere Reflexion.
