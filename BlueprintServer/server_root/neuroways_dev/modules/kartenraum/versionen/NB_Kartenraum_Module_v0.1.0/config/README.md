# Module Config Contract

Produktive Werte werden durch Environment/Core geliefert. Keine Secrets im Modul.

Benötigte Schlüssel:
- `module.enabled`
- `module.route_base`
- `persistence.connection_key`
- `identity.scope_provider`
- `features.allow_redraw`
- `features.journal_enabled`
- `assets.base_url`
