# NB Kartenraum Backend v0.4.1

Read-only Backend mit drei Content-Ebenen:

- `cards.php` → technische Karten-/Sheetdaten
- `text.php` → persönlicher NeuroWays-Kartenraum
- `knowledge.php` → Kartenwissen

Zentrale DB-Konfiguration bleibt `/config/database.php`.
Connection-Key bleibt `platform`.

Erwarteter Bestand:
- 78 Karten
- 156 Kartenraum-Texte
- 156 Kartenwissen-Datensätze
