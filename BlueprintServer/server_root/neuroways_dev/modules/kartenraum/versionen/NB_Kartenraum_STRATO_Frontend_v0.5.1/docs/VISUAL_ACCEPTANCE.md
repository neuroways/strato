- Große Arkana:
  - Der Narr → SheetA-2 Position 1
  - Der Hierophant → SheetA-2 Position 6
  - Die Liebenden → SheetB Position 1
  - Der Stern → SheetC Position 6
  - Die Welt → SheetD Position 4

- Stäbe:

  - Zehn → SheetF Position 4
  - König → SheetG Position 4

- Kelche:
  - Drei → SheetH Position 3
  - Sieben → SheetI Position 1
  - Königin → SheetJ Position 3

- Schwerter:
  - Vier → SheetK Position 4
  - Zehn → SheetL Position 4
  - Ritter → sheetM Position 2

- Münzen:
  - Sechs → SheetN Position 6
  - Acht → SheetO Position 2
  - König → SheetP Position 4

- Rückseite:
  - SheetR Position 5

Abnahmefehler:
- vollständiges Sheet sichtbar
- verzerrte Illustration
- benachbartes Panel sichtbar
- falsche Karte
- Beschriftung Bestandteil des Bildes
