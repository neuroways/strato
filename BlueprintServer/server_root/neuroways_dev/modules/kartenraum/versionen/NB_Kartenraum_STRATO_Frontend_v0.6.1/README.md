# NB Kartenraum Frontend v0.6.1

## Änderungen
- Einstieg vor Anmeldung und Ziehung tatsächlich eingebaut.
- Alle neu eingeführten Texte redaktionell überarbeitet.
- Kürzere Überschriften und mobil robustere Textblöcke.
- Formulierungen zu Tarot und Tagesziehung eigenständig neu geschrieben.
- Die bisherige `nb_card_knowledge`-Anzeige ist im Frontend vorläufig deaktiviert.

## Wichtig zum Urheberrecht
Die Datenbanktabelle `nb_card_knowledge` enthält laut aktuellem Datenbestand `source-derived-draft`-Texte.
Diese werden in v0.6.1 bewusst NICHT angezeigt, weil sie vor Veröffentlichung vollständig in eigenständige
NeuroBalance-Texte überführt werden müssen.

Die redaktionellen `nb_card_text`-Inhalte bleiben Teil des Schritt-3-Ablaufs.
