# Kartenwissen API v0.4.1

## Endpoint
`GET api/knowledge.php?id=major-00&audience=ADULT&language=de`

Antwort enthält:
- `theme`
- `keywords`
- `meaning_text`
- `symbolism_text`
- `other_direction_text`
- `status_code`
- `provenance_code`

Persönlicher Kartenraum (`text.php`) und Kartenwissen (`knowledge.php`) bleiben getrennte Endpunkte.
