# NB Kartenraum Frontend v0.5.4

Ziehungs-UX neu:

1. Ein Klick auf das Symbol `✦`.
2. Nur die Kartenrückseite ist sichtbar.
3. Eine kurze ruhige Magie-Sequenz läuft.
4. Die Karte dreht sich automatisch um.
5. Der Kartenname ist direkt sichtbar.
6. Bei REVERSED bleibt sie zunächst auf dem Kopf.
7. Optional kann sie mit `↻` nur zur Betrachtung gedreht werden.
8. Der Hinweis `Umgekehrt gezogen` bleibt erhalten.

Kein zweiter Klick zum Aufdecken mehr.

Zusätzlich:
- Fragezeichen-/Fehlerzustände der alten Reveal-Logik entfernt.
- Kartenrückseite wird bereits im Ausgangszustand vorbereitet.
- Backend bleibt v0.5.0.
