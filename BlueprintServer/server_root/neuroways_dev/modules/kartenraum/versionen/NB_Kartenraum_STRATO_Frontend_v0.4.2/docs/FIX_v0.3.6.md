# Fix v0.3.6

Nach `Kartenraum öffnen` wird der DB-Textbereich jetzt ausdrücklich eingeblendet und in den sichtbaren Bereich gescrollt.

- Titel und Untertitel
- Was siehst du? / Was entdeckst du?
- Raum der Karte
- tragende/hilfreiche Seite
- schwierige Seite
- Kontextfragen
- eigene Kartensprache
- möglicher nächster Schritt

Backend v0.3.3 und MariaDB bleiben unverändert.
