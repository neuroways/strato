# NeuroBalance Kartenraum Frontend v0.4.2

Datenbankgestütztes Frontend mit getrennten Ebenen:

1. Karte / Illustration
2. eigene Wahrnehmung
3. persönlicher Kartenraum
4. optional: „Mehr über diese Karte erfahren“

Backend:
`../NB_Kartenraum_Backend_v0.4.1/api/`

Kartenwissen wird erst auf ausdrücklichen Klick über `knowledge.php` geladen.
Die persönliche Reflexion bleibt dadurch klar vom allgemeinen Kartenwissen getrennt.
