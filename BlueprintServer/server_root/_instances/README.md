# Instance State

Installations-/kundenbezogener veränderlicher Zustand. Derselbe Server kann mehrere voneinander isolierte Instanzen tragen.

## Regeln

- Keine Package-Codekopien als Source of Truth.
- State muss instance- und environment-scoped bleiben.
