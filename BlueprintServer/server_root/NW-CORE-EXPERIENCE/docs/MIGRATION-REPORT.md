# Migration Report

- React/Next/Vinext
- Cloudflare Worker
- D1/Drizzle Scaffold
- ChatGPT-spezifische Anmeldung
- Node-Laufzeit im Hosting

## Erhalten

- visuelle Grundrichtung
- Desktop- und Mobile-Navigation
- sechs Wirkmodi
- Bewegungsreduktion
- vierstufiger Check-in
- momentane Verortung
- Auswahl der weiteren Tiefe
- Demo „Mein Weg“

## Nicht implementiert

- produktive Speicherung
- Benutzeridentität
- Installation Registry
- zentraler NeuroWays Context Resolver
- PRO-Deployment

Der Pilot ist ein isoliert testbares Artefakt, noch keine freigegebene Core-Version.
