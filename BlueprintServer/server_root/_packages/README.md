# Package Repository

Serverweiter, privater Store für versionierte Core- und Module-Artefakte. Das Vorhandensein eines Pakets ist keine Installation.

## Regeln

- Verified Versionen sind immutable.
- Ein Upload aktiviert oder aktualisiert keine Installation automatisch.
